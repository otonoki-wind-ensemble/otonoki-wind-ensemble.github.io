# 楽団 音ノ樹 公式HP

公開URL：https://otonoki-wind-ensemble.github.io

## しくみ
- このリポジトリ：見た目（HTML/CSS/JavaScript）だけ。サーバー側のプログラムはありません
- 情報：Googleスプレッドシート「HP管理シート」→ Apps Script が公開してよい項目だけを返す → `app.js` が表示
- 見学申込：Googleフォーム（個人情報はGoogle側にのみ保存）

## 情報を更新したい
**このリポジトリは触らず、HP管理シートを編集してください。** 数分以内（通常は即時）に反映されます。

| 直したいもの | シートのタブ |
|---|---|
| 紹介文・練習・団費・SNS・フォームURL | 基本情報（「項目」列の名前は変えない） |
| 募集パート | 募集パート |
| 演奏会・館まつり（あゆみにも自動で載る） | 本番 |
| 曲目・曲の動画・トップの動画 | 曲目 |
| あゆみ（本番以外のできごと） | できごと |
| 団員の声 | 団員の声（掲載同意と表示にチェック） |
| よくある質問 | FAQ |
| 写真 | 写真（Googleドライブの共有リンク） |

## このリポジトリを触るのは
- Apps Script のURLが変わったとき → `config.js` の `dataUrl` を書き換える
- トップの背景写真を入れる／替えるとき → `images` に写真を置き、`config.js` の `heroImage` にファイル名
- デザインを変えるとき → `style.css` / `index.html`

## ファイル
| ファイル | 役割 |
|---|---|
| index.html | ページの骨組み（文章・情報はすべてシートから読み込む。読み込めないときはエラーメッセージのみ表示） |
| style.css | 見た目 |
| app.js | シートの情報を読み込んで表示 |
| config.js | 設定（データの読み込み先、背景写真） |
| images/ | ロゴ・写真 |
| .nojekyll | GitHub Pages の変換処理を止めるための空ファイル（消さない） |

## 安全のための決まり
- 外部のプログラム部品（ライブラリ）は使わない
- パスワード・個人情報をこのリポジトリに置かない（公開リポジトリのため誰でも見られる）
- 組織の2段階認証を必須のままにする
